# opencode-setup

Мой рабочий конфиг OpenCode и заметки к нему.

## Что это

OpenCode — терминальный кодинг-агент. Он читает конфиг из
`~/.config/opencode/opencode.jsonc`. Здесь лежит моя версия с настройками,
которые уменьшают расход токенов на длинных сессиях.

## Зачем такие настройки

### Компакция без фоновых сводок

Когда диалог подходит к пределу контекста, OpenCode заменяет старую часть
разговора сводкой. По умолчанию сводка пишется заранее, в фоне, пока сессия
продолжается.

Проблема: если сессия закончится раньше, чем сводка понадобится, токены
уже потрачены. На бесплатных и ограниченных тарифах это чистый перерасход.

Поэтому:

```jsonc
"compaction": {
  "auto": true,
  "background": false
}
```

Сводка по-прежнему пишется, но только в момент, когда она действительно нужна.

### Сводки на отдельной модели

Сама сводка — это большой запрос. Если писать её той же моделью, что и код,
она съедает квоту основного провайдера. Отдельная модель для компакции
снимает эту нагрузку:

```jsonc
"agents": {
  "compaction": { "model": "opencode/glm-5.3-flash-free" }
}
```

Если указанная модель недоступна, OpenCode откатывается на модель сессии,
так что конфиг не ломается.

## Как применить

Скопировать `opencode.jsonc` в `~/.config/opencode/opencode.jsonc`
(на Windows — `C:\Users\<имя>\.config\opencode\opencode.jsonc`).

Изменения подхватываются автоматически, перезапуск не нужен.
